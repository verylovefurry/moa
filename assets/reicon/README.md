# Reicon UI assets

Selected Outline icons from [Reicon](https://reicon.dev/icons), sourced from the
[official canonical dataset](https://github.com/dqev/reicon/blob/fe6975391b80c808c25d98b2a21081cf180482f9/data/icon-data.json).

The original paths and 24 × 24 viewBox are preserved. Only the SVG wrapper is added;
the application applies its text color at render time. All control/navigation icons
use a 16-unit slot with the same 1×, 1.5×, 2× and 3× rendering policy.

Copyright © 2025 REICON. The upstream MIT license is included in `LICENSE` and
bundled with the application. Upstream credits Solar Icons by 480 Design
(CC BY 4.0) and Zappicon as source elements; see the
[Reicon credits](https://github.com/dqev/reicon/tree/fe6975391b80c808c25d98b2a21081cf180482f9#credits).

`source.json` records the verified revision and original name of every asset.
No runtime network request or additional icon package is required.
